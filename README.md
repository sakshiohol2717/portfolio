# Sakshi Ohol – React Portfolio (frontend only)

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Customize
1. Edit `src/data.js` – name, email, phone, GitHub/LinkedIn links, project links.
2. Put your resume PDF in `public/` as `Sakshi_Ohol_Resume.pdf`.
3. Colors live in `:root` at the top of `src/index.css`.

## Deploy (free)
Push to GitHub, then import the repo on Vercel or Netlify (build: `npm run build`, output: `dist`).
